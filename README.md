# Public Domain Data
All data, code and documentation in this repository are freely reusable with no restrictions. This is usually for one of the following reasons:

- all rights have been waived by CC0.
- all rights have expired.
- no rights ever subsisted.

## Contents

- [authors](https://github.com/drgavinr/pd-data/tree/main/authors): list of authors who wrote publications or theses relevant to the British Civil Wars. Most with Wikidata IDs.
- [compounding](https://github.com/drgavinr/pd-data/tree/main/compounding): structured data about cases and people listed in *Calendar of the Committee for Compounding*.
